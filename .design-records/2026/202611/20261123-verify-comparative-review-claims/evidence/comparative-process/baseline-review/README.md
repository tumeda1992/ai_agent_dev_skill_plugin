# 採用理由の引渡しに関するレビュー

同じ三本のラインを扱う共有台帳案（週200）と通知アプリ案（週600）について、比較から実装担当への引渡しまでを調べた。対象は [決定手順](../inputs/decision-process.md) と [合成の比較資料](../inputs/materials.md)。

現行手順では、候補名も費用も本人の応答も正しいのに、「三本の不具合を一覧できるからアプリを選ぶ」と引き渡せる。一覧は現行台帳でも読める。本人が追加400で選んだのは、発生直後に担当班へ知らせ、発生を知るまでの巡回待ちを減らすことだった。提示済みの成功例ではこの違いを説明できている。
