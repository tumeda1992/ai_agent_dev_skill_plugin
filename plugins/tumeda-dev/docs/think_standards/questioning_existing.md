# 既存のものを消す・残すを判断する

**主軸: 理由を歴史的経緯と合理的必然性へ分離し、必然性だけを残す**

既存の記述、構造、規則、codeが「なぜそこにあるか」には、二つが混ざっている。そう置くほかなかった理由（合理的必然性）と、たまたまそこへ置かれた理由（歴史的経緯）である。ゼロベースで考えるとは、この二つを分離し、必然性だけを残すことを指す。

- やってしまいがちな行動: 現状の構造を出発点にして、「今そこにあるから要る」または「別に正本があるから要らない」で判断する
- それをやると何が起きるか: 前者では歴史的経緯がそのまま必然性として引き継がれ、不要なものが増え続ける。後者では必然性のあるものまで一緒に落ちる。どちらも現状の配置を疑っていない点で同じ誤りである
- 正しい判断のための問い: **「これが今そこにあるのは、そう置くほかなかったからか、たまたまそこへ置かれたからか」**
- 分離した結果は三つに分かれる。必然性があり配置も正しい（残す）、必然性はあるが配置が誤っている（移す）、必然性がない（消す）。二択で考えると「移す」が見えなくなる

## 補助: 必然性は運用の中でしか測れない

必然性を「原理的に必要か」で測ると、実在する運用が落ちる。測る場所は運用である。

- やってしまいがちな行動: 「規則は正本に書いてあるのだから、複製は原理的に不要」と判断する
- それをやると何が起きるか: 正本が読まれない運用経路が実在した場合、そこへ規則が届かなくなる。原理では不要でも、運用では唯一の伝達経路だったという形で現れる
- 正しい判断のための問い: **「この対象が読まれる経路を全部数えたか。そのうち、正本を読まない経路はあるか」**
- 運用を外したゼロベースは、机上で筋が通っているぶん反証されにくい。筋が通っていることを根拠に採らない

## 補助: 複製と所在の指示を区別する

必然性の測り方は、対象が複製か所在の指示かで変わる。

- 複製は、元が更新されても追随しない。古い複製と新しい正本が併存し、読み手がどちらに従うか決まらなくなる。冗長化は確実性を上げず、矛盾の余地を作る
- 所在の指示は、元が更新されても指し先が変わらない限り腐らない。読まれる経路を増やす効果だけが残る
- 正しい判断のための問い: **「これは規則そのものか、規則の在り処か」**。前者なら正本一箇所へ寄せ、後者なら経路の数だけ置いてよい

## 失敗例

ある規則が、正本となる文書と、そこから生成される成果物の両方に書かれていた。重複を理由に成果物側を消そうとしたところ、規則のうち一つは正本側に存在せず、成果物側だけが持っていた。

このとき起きていたことは次の三つである。

1. 「重複だから消す」という判断が、重複していない項目まで巻き込んだ
2. その項目の正本がどこであるべきかを問わないまま、消すか残すかの二択で考えていた
3. 成果物は、正本を読まずに開かれる運用経路を持っていた。正本へ寄せるだけでは、その経路へ規則が届かなくなる

分離してみると、その項目は必然性があり、配置だけが誤っていた。正本へ移し、成果物側には所在の指示だけを残す形が答えになった。
