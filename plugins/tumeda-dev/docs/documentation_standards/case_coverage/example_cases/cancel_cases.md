# 旅行予約のケース — 一部・全部をキャンセルする

旅程の一部または全部を取り消すケース。全体の地図は [`overview.md`](./overview.md)、旅程の組み立て・人数変更は [`main_cases.md`](./main_cases.md)。各ケースは観点〈**予約状態・課金/返金・旅程の見え方**〉で示す。

予約を取り消す。**どの予約を・発券前後・もう片方の予約の状態**で結果が変わる。片方だけ消えると旅程が壊れる。「どちらを取り消すか」で 2 つに分かれる（→ は結果。「発券済なのに宿無し」が最も厄介）。

**航空券をキャンセルする**（もう片方＝ホテル）:

| 航空券 ＼ ホテル | ホテル予約済 | ホテルキャンセル | ホテル未予約 |
| --- | --- | --- | --- |
| **未発券** | → 航空券だけ消えた・返金 | → 全キャンセル | → 手続き中 (キャンセル, 未予約) |
| **発券済** | → 同上・**払戻制約** | → 全キャンセル・払戻制約 | → 手続き中 (キャンセル, 未予約)・払戻制約 |

**ホテルをキャンセルする**（もう片方＝航空券）:

| 航空券の状態 | 結果 |
| --- | --- |
| 予約済（未発券） | → ホテルだけ消えた |
| 発券済 | → **発券済なのに宿無し（最厄介）** |
| キャンセル | → 全キャンセル |
| 未予約 | → 手続き中 (未予約, キャンセル) |

### CX-1. 未発券の航空券をキャンセル

- 予約状態: 航空券＝キャンセル。もう片方（ホテル）の状態で行き先が変わる（生存＝「航空券だけ消えた」／既にキャンセル＝全キャンセル／未予約＝手続き中へ戻る）。
- 課金/返金: 手数料なく全額返金。
- 旅程の見え方: 片方だけ消えた／全消滅／手続き中、のいずれか。

### CX-2. 発券済の航空券をキャンセル

- 予約状態: 航空券＝キャンセル（発券済からの取消）。分岐は CX-1 と同じ。
- 課金/返金: **払戻制約**（手数料／取消不可）。取り消せても返金額が目減り、または取消不可。
- 旅程の見え方: CX-1 と同じ行き先だが、返金が目減り／取消不可。

### CX-3. ホテルをキャンセル（航空券は未発券）

- 予約状態: ホテル＝キャンセル／航空券＝予約済（生存）。
- 課金/返金: 手数料なく全額返金。
- 旅程の見え方: 泊まる所が無いのに航空券が残る。航空券も取り消すか／代替宿を取るかの確認待ち。

### CX-4. ホテルをキャンセル・航空券は発券済（最厄介）

- 予約状態: 航空券＝発券済（取消不可が残る）／ホテル＝キャンセル。
- 課金/返金: ホテルは返金。航空券は払戻制約（不可／目減り）。
- 旅程の見え方: **最も壊れた状態**（現地に着くが宿無し）。強く警告し代替宿を促す。

### CX-5. 全部キャンセル

- 予約状態: 航空券・ホテルとも キャンセル。
- 課金/返金: 両方の返金を確定。
- 旅程の見え方: 旅程消滅（クローズ）。
