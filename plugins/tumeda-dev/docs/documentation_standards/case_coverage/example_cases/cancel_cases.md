# 旅行予約のケース — 一部・全部をキャンセルする

旅程の一部または全部を取り消すケース。全体の地図は [`overview.md`](./overview.md)、旅程の組み立て・人数変更は [`main_cases.md`](./main_cases.md)。

予約を取り消す。**どの予約を・発券前後・もう片方の予約の状態**で結果が変わる。片方だけ消えると旅程が壊れる。「どちらを取り消すか」で 2 つに分かれる（→ は結果。「発券済なのに宿無し」が最も厄介）。

**航空券をキャンセルする**（もう片方＝ホテル）:

| 航空券 ＼ ホテル | ホテル予約済 | ホテルキャンセル | ホテル未予約 |
| --- | --- | --- | --- |
| **未発券** | → 航空券だけ消えた・返金 | → 全キャンセル | → 手続き中 (キャンセル, 未予約) |
| **発券済** | → 同上・**払戻制約** | → 全キャンセル・払戻制約 | → 手続き中 (キャンセル, 未予約)・払戻制約 |

**ホテルをキャンセルする**（もう片方＝航空券）:

| 航空券の状態 | 結果 |
| --- | --- |
| 予約済（未発券） | → ホテルだけ消えた |
| 発券済 | → **発券済なのに宿無し（最厄介）** |
| キャンセル | → 全キャンセル |
| 未予約 | → 手続き中 (未予約, キャンセル) |

### CX-1. 未発券の航空券をキャンセル

手数料なく取消・全額返金。もう片方（ホテル）が生きていれば「航空券だけ消えた」、既にキャンセルなら全キャンセル、未予約なら手続き中へ戻る。

### CX-2. 発券済の航空券をキャンセル

払戻に制約（手数料／不可）。取り消せても返金額が目減りする、または取消不可。

### CX-3. ホテルをキャンセル（航空券は未発券）

手数料なく取消・全額返金。泊まる所が無いのに航空券が残るので「航空券も取り消すか／代替宿を取るか」を確認する。

### CX-4. ホテルをキャンセル・航空券は発券済（最厄介）

発券済で取り消せない航空券が残り、宿だけ消える。現地に着くが泊まる所が無い＝旅程が最も壊れる。強く警告し代替宿を促す。航空券は払戻可否のみ案内、ホテルは返金。

### CX-5. 全部キャンセル

両方取消。旅程消滅。両方の返金を確定してクローズする。
