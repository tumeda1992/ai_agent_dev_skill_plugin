# CR-NNN: 影響が分かる具体的な指摘名

- 優先度: P1 / P2 / P3（理由を問題本文へ記載）
- 対象スナップショット: 完全SHA。作業treeなら内容hashの記録先
- 対象: path、関数・class、対象版での行番号
- 観点: 正確性 / 認可 / データ整合性 / 責務 / 重複 / 運用等
- 由来: 差分で導入 / 既存 / 全体レビュー。旧指摘との対応があれば記載
- 採否: 未判断 / 採用 / 見送り / 保留 / 撤回
- 対応状況: 未着手 / 対応中 / 完了
- 適用枠: 挙動維持で可 / 挙動変更が必要 / 要調査
- 依存する指摘: なし、または固定IDの相対リンク

## 問題と根拠

発生条件、具体的なコード、期待との相違、利用者への影響を書く。
確認した事実と未確認の推測を区別する。優先度の根拠を示す。

## 改善案

どの責務・呼出し・保存をどう変えるかを書く。
安全に提案できない場合は不足する材料と調査先を明記する。

## 振る舞いへの影響

維持する戻り値・例外・順序・副作用・公開APIと、変更する挙動を示す。
当初の適用条件から外れるなら、その条件を具体的に書く。

## 検証方法・証拠

再現手順、関連テスト、期待結果。静的確認 / 実行済み / 未実施を区別する。
再現テストの成功と修正テストの成功を混同しない。

## 合意・適用記録

- 合意した指示と対象範囲: 未合意
- 修正内容・判断理由: 未適用
- 実行した検証と結果: 未実行
- 適用コミット: 未適用
