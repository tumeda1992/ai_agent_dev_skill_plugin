
# 議論記録の保存形

## 論点metadata

```markdown
## 論点N: {判断内容を表すタイトル}

**ステータス:** {調査中 / 提案中 / 子論点待ち / 決定 / 保留 / 分解済み}

**親論点:** 論点M

**種別:** {TBDヒアリング / 認識齟齬 / レビュー指摘。複数可}
```

## 回の骨子

```markdown
### イテレーションI（論点N）: {この回で進める内容}

#### 提案背景（論点N・イテレーションI）

{今回の判断・応答に必要な事実、条件、決め手、代償と限界を説明する本文}

```

## 提案本文

```markdown
#### 提案I（論点N）

{その回の問いを判断できる案}
```

## 空の提案応答欄

```markdown
#### 提案Iへのフィードバック（論点N）
```

## 受領応答の本文

```markdown
**結果:** {その回の結果が分かる短い表現}

> {user feedback、review等を必要な範囲で原文のまま示す}

{評価・得られた入力・訂正・残る不足の補足}
```

## 仮決定

```markdown
### 仮決定（論点N）

{現在有効な仮の判断}
```

## 再開条件

```markdown
### 再開条件（論点N）

{不足、解消を判断するevent・evidence・action、再開する未決判断}
```

## 決定

```markdown
### 決定（論点N）

{現在有効な最終結論と、その制約・選択理由}
```
