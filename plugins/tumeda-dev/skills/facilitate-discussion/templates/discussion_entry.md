
# 議論記録の保存形

## 論点metadata

```markdown
## 論点N: {判断内容を表すタイトル}

**ステータス:** {調査中 / 応答待ち / 子論点待ち / 決定 / 保留 / 分解済み / 反映待ち / 反映済み}

**親論点:** 論点M

**種別:** {TBDヒアリング / 認識齟齬 / レビュー指摘。複数可}
```

## 回の骨子

```markdown
### イテレーションI（論点N）: {この回で進める内容}

#### 検討記録（論点N・イテレーションI）

{今回の判断・応答に必要な事実、条件、決め手、代償と限界を説明する本文}

[内部検討記録: 論点N・イテレーションI]({内部log相対path}#iteration-I)
```

## 提案本文

## 変更内容

```markdown
### イテレーションI（論点N）: 変更の報告

#### 変更内容I（論点N）

変更前と変更後、原因となった原文と出典、既決事項または委託の根拠、対象と範囲、理由、検証と限界を書く。

#### 検討記録（論点N・イテレーションI）

内部logの該当回・recordへのlinkと、この変更を理解するための背景を書く。
```

## 現在の変更

```markdown
### 現在の変更（論点N）

iteration、報告した問いまたは完了reviewと版、対象、報告の有無と出典、対応する実応答と原文への参照、反映状況と検証結果、未解決を書く。
```


### 変更の記入例

架空の例であり、実際の合意・検証ではない。実物には対象path・節、原文・内部logの実在する出典を付ける。

```text
#### 変更内容0（論点N）

判断根拠: 合意からの導出。
合意済みの「分割後の入口を一つにする」に従い、案内文の参照を同名索引へ揃える。
変更前は単一入口、変更後は同名索引。対象は案内文の該当link全て。原文・採番・承認条件は保持する。

#### 検討記録（論点N・イテレーション0）

参照先と更新対象を照合した経緯を説明し、同番号の内部logへ結ぶ。

### 現在の変更（論点N）

iteration0、報告版1、対象は案内文。未報告・未反映。
次の問いまたは完了reviewの直前に報告し、実際の問いと版をここへ記す。
次の当該応答後に、その出典・適用結果・検証・未完を更新する。
```
