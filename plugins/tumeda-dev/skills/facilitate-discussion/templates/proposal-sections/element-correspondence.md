# 少数要素の対応を表で示す

## 使用条件

要素が少なく、各要素を同じ少数の観点で照合する時に使う。列の意味が自明で、cellが短く、要素集合と観点が議論直後に独立して成長する見込みが低い場合を扱う。

## template

```markdown
| {要素} | {共通観点1} | {共通観点2} |
| --- | --- | --- |
| {...} | {...} | {...} |
| {...} | {...} | {...} |
```

表を要素分解一般のdefaultにしない。cellが一文を超えて育つ、観点が要素ごとに異なる、要素が独立した話題へ進化する場合は、小見出し、階層箇条書き、散文等へ切り替える。表現の選択は`plugins/tumeda-dev/docs/documentation_standards/expression_notation.md`に従う。
