# 重い選択肢を提示する

## 使用条件

複数案からユーザーが選ぶ必要があり、各案の理解に複数段落、表、tree、図、代表例等が必要な時にwrapperとして使う。各案の内部には、complete stateや他の内容patternを必要に応じて組み込める。

## template

```markdown
##### a. （推奨）{選択肢を一文で書く}

{この案の内容を、必要な段落、固有見出し、表、tree、図、代表例等で示す。}

##### b. {選択肢を一文で書く}

{この案の内容を、必要な段落、固有見出し、表、tree、図、代表例等で示す。}

##### c. {選択肢を一文で書く}

{この案の内容を、必要な段落、固有見出し、表、tree、図、代表例等で示す。}

{推奨の理由を、全ての案の後に書く。}
```

ユーザーが`a`、`b`、`c`だけで選べる添字を保つ。推奨・仮決めの印は、案の前に別の行として書かず、該当する案の行の添字の直後に付ける。案の文を全部読まなくても、どれが推されているかが分かるためである。確かめるだけの論点を仮決めとして示す時は「（推奨）」の代わりに「（仮決め）」を付け、理由として根拠を名指す（[round-trip.md](../../round-trip.md)）。各案の見出し自体で選択肢を一文表示し、その配下を案ごとの説明領域にする。すべての案へ同じ固定小見出しを要求せず、比較に必要な具体像とpatternを案ごとに選ぶ。
