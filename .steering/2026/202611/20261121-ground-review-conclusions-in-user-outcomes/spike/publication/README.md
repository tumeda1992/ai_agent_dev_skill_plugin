# 確認した協力先の案内を公開する

地域のイベントの案内に協力先の一覧を載せる。来場者は複数の協力先を自由に組み合わせて利用でき、一つの事業者で必要品を揃えるという制約はない。
確認済みの案内に今回の必要品が全て登場する場合、確認済みの協力先を全て入力順で公開する。一部の協力先が必要品の一部だけを扱う場合も、その案内は一覧に含める。価格の比較は行わない。
必要品は空でない集合。idは一意で入力の形も受付が確認済み。どこにも登場しない必要品があれば、案内を補うためNoneを返す。
既出の指摘「未確認の案内も公開に混じる」は、確認済みだけを読むよう修正済み。下の実装はその修正を含む。
