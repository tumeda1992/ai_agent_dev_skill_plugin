# 備品の調達先を選ぶ

イベントに必要な備品の調達先を、確認済みの見積から選ぶ。会場は一つの事業者にまとめて注文する契約で、今回の必要品を全て扱える事業者のうち提示金額が最も安いものを返す。
確認済みの見積はid・提示金額・扱える品目を持つ。金額は同じ通貨の非負整数で、今回の必要品一式についてその事業者が提示した値。値段を品目ごとに合算する処理は対象外。
条件を満たす事業者がなければNoneを返す。必要品は空でない集合。金額の同値時は入力順で選んでよい。
受付側が入力の形と事業者idの一意性を確認済み。今回は外部への発注や保存を行わず、選定結果を担当者へ返す処理を検討する。
既出の指摘「未確認の見積も選定に混じる」は、確認済みの見積だけを読むよう修正済み。下の実装はその修正を含む。
