## 抜け漏れ検証の使い方

1. 塊の冒頭で示した分岐に、対応するケースが揃っているか確認する。
2. 無ければ「対象外」に該当するか確認。該当しなければ抜け漏れ。
3. 掛け合わせ・状態遷移で組んだ網羅を、QA レビュアーの目（隠れ状態・並行/順序・値境界・書き忘れた不変条件）で崩しにいく。
4. ケースを具体化する過程で新たな分岐が出たら、塊冒頭の説明とケースに足す。
