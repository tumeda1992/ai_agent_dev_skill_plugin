# 内部検討記録の保存形

## 論点の骨子

```markdown
# 内部検討記録: 論点N — {対象の問い}

**discussion:** [{discussion basename}]({discussion相対path})

**論点:** 論点N

## 開始context

{問題、対象語の意味、決める範囲、開始時の既決条件、残る不足}
```

## 回の骨子

```markdown
<a id="iteration-I"></a>

## イテレーションI: {この回の問い}

{今回の入口、変わった前提、使う既存根拠}
```

## 記録単位

```markdown
<a id="iteration-I-record-R"></a>

### {用途}: {何を調べ、判断し、確かめるかを表すタイトル}

{選択した目的別formatの入力と結果}
```
